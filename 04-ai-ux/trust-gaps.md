# Trust-Gap Mitigations · Juno

_Module 4. Generated by `M4 - AI-UX Trust Gap Checker.html`. Feature: Juno PM v1 (working prototype with strategy retrieval + tool trace). Paste over `04-ai-ux/trust-gaps.md`._

## Trust gaps

| Gap | Where it shows up | User cost | Mitigation |
|---|---|---|---|
| **The Black-box Gap** | Can the user see why the AI decided? | Largely closed (4/5) | A live Tool trace panel logs every tool call Juno makes, in order, so the PM sees the actual reasoning path. Each Insight Card also carries a Strategic Traceability footer: the transcript quote, the Source ID, and the strategic pillar it maps to. No rank appears without a visible reason. |
| **The Hallucination Gap** | Could this confidently be wrong? | Largely closed (4/5) | Grounding is live: `search_strategy` retrieves from the loaded strategy corpus before Juno ranks anything, so priorities cite real sources rather than model guesses. The M3 verbatim-citation gate badges any unsupported item "Unverified" instead of showing it as fact, and never silently drops it. The "never invent" rule blocks fabricated names, ARR, dates, or ticket numbers. |
| **The Control Gap** | Can the user steer or stop? | Closed (4/5) | Manual Override on every Insight Card (re-tag P0-P3, edit rationale, mark notRecommended), plus individually editable and regenerable PRD blocks. Copilot autonomy: the PM approves before anything publishes, so nothing auto-sends. |
| **The Intelligence Tax** | Is the latency / privacy / cognitive load worth the value? | Noticeable but recoverable (3/5) | Breadcrumb status turns wait time into visible progress against a p95-under-5s target. PII is scrubbed pre-LLM and opinion-heavy sources are excluded. Output is capped at the top 3 (max 5 rows) and shown inline, so the PM reviews in flow. Open risk: retrieval quality is the known bottleneck, so weak chunks can still add cognitive load. |

## Highest-priority fix

**The Hallucination Gap, retrieval-quality edge (4/5).**

With the Tool trace and grounding now live, black-box visibility is largely handled. The remaining risk sits where my own build surfaced it: retrieval quality was the bottleneck, and chunking strategy mattered more than the model. A confident, well-cited priority built on a weakly-retrieved chunk is the most dangerous failure left, because it looks trustworthy. The fix is tightening the verbatim-citation gate and the retrieval/chunking so a citation only passes when it genuinely supports the claim, validated against the M6 golden set.

## Verdict

**Conditional Go.** Safe to run as a bounded pilot in Copilot mode: grounding and the audit trace are live, the PM approves every publish, and the Manual Override gives a working stop on each card. Hold on any autonomous or auto-publish behaviour until the M6 evals return a real accuracy number and the retrieval-quality gate is validated. Ship the assistive draft experience now; earn the autonomy later.
